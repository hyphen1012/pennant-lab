# PENNANT LAB — 場所・媒体・重要度の演出方針

ユーザー提供の参考画像（監督室、球場、本部業務一覧、紙の月例会議、端末内の業務メール・球界ニュース・結果報告）に基づく。参考元の素材・キャラクター・画面を複製せず、独自のデザインで「どこで何を確認しているか」を表現する。

## 共通原則
- 通常は暗い紺・黒・金。報告の紙面・端末内は白〜明るいグレーを中心にしてメリハリをつける。文字の読みやすさとスマートフォンの操作性を優先。
- 場所別背景：球場、本部執務室、監督室、会議室、医務室、練習場。実際の機能に応じて追加。背景は文字を邪魔しない減光・グラデーションを重ねる。
- 媒体：月次会議は紙の資料（表紙、順番にページめくり、最後に会議終了）、週次の内部報告は業務メール、球界ニュースは外部メディア、試合結果は端末内の速報・詳細、経営分析はPC管理画面を候補とする。既存の週次ニュース・速報・試合結果の保存と進行仕様を維持する。
- 業務重要度：必須＝赤系、推奨＝金系、任意＝青緑系、一般情報＝紺。枠・内側背景とも控えめなグラデーションを使用。色だけでなく文字ラベルで識別し、本当に必須の処理だけを必須とする。通常選手の能力色や特別選手の肩書色とは別系統。

## 実装順序
1. v0.9.14 本部トップ・業務一覧。独自SVG背景（夕暮れの球場、執務室）、順位・ファン・総年俸、共通グラデーション業務カード。編成は推奨、監督契約・不満や資金状況に応じて推奨、補強等は任意。年度末の必須手続きは赤系。新規の進行制限なし。
2. 監督室：背景、導入演出、面談の会話・指示画面。
3. 月例会議：明るい紙資料、ページ切替、戦績・業務・故障・収支。既存データ・決済・確認条件を維持。
4. 週次報告・ニュース・試合結果を端末内の異なる媒体として再設計。
5. 財務・経営の分析画面、医務室・キャンプ等の背景を実装済み機能に合わせて拡張。

## v0.9.15 第2〜7段階の初回実装
監督室の入室と面談、月例会議の5ページ（表紙、戦績、業務・育成、故障、収支）、前後ボタンと横スワイプ、最後のページまで会議終了不可。月次の故障・対戦結果を新規記録し旧版不足分は明示。週次は球団運営スタッフからの内部メールと外部ニュースに分離し、精算済みの金額のみ掲載。通常・倍速はメールと紙面の表示を順番に行う。ニュースと試合結果の端末枠・明るい画面、医務室背景、財務PC管理を追加。試合観戦・得点・GAME SET演出、収支計算、セーブv2は維持。練習場等の背景と詳細な業務機能は今後拡張。

## v0.9.16 ユーザー確認後の調整
明るい報告媒体の勝・敗・分カードは淡い青・赤・黄色を使用し、文字も対応する濃色にする。週次メール、球界ニュース、月例会議に共通適用。紙のページ送りは0.42秒から1.2秒、最大回転角13度から67度に変更し、左右方向の陰影を追加。収支の緑・赤見出しは白文字で読みやすくする。ページの確認条件やデータ処理は変更しない。動きを減らす設定を尊重する。

## v0.9.17 半面ページめくり
ユーザー指定：紙全体が裏返る動きを廃止し、進む際は左半面固定・右半面が中央軸でめくれ、戻る際は右半面固定・左半面が逆方向にめくれる。旧ページの固定半面と可動半面、次ページを別レイヤーとし、1.2秒で下の紙面を現す。固定側は終盤まで動かさない。めくれる半面だけに紙の陰影を追加し、表紙を開く際にはめくりを行わない。操作ボタンはアニメーション中に回転しない。ページ確認・保存・収支・勝敗分の配色は変更なし。端末の動きを減らす設定では即時切替。

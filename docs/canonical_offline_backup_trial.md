# H009 停止時バックアップ・復旧試作

ステージングの5 SQLite DBを、外部で全サービス・全ワーカー・全書込を停止した後にのみ別の新規0700ディレクトリへ退避する。停止確認フラグは操作者の申告であり、排他ロックやライブバックアップの保証ではない。WAL/SHM/journalや未知のDB、symlink/hardlink、既存ディレクトリ、重複パスを拒否。既存DBを上書きしない。ファイルのサイズ・SHA256、SQLite quick_check、コピー前後の同一性を検査。manifestは最後に書く。復旧先も新規のみ。CIは合成試験DBを使用し、元データ・backupを変更しないことと復元先の実HTTP世界ID/revision/財布/複数slotを照合する。CIから生DBや秘密情報を公開しない。

正式運用では外部で停止・排他を保証し、暗号化保管、アクセス管理、署名または信頼できる別経路のハッシュ、バックアップ世代・RPO/RTO、削除/返金/権利の再照合、障害時の手順、OSメモリ上限、長期DB規模、端末検証が必要。試作manifestは偶発的破損検知であって改ざん証明ではない。電源断に対する原子的・耐久性保証や本番復旧承認は未完。provider資格情報は対象外。デプロイ・公開なし。

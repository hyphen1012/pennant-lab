# H014 秘匿階級の投影制限

ドラフト候補・外国人候補/交渉・新人段階公開・特殊速報の既存hidden条件に連動してcategory/specialCategory/originCategory（該当項目）をnull化。最終公開時は従来の階級を返す。外国人第1段階の既定能力公開は維持。新人/速報の前世情報はseed/baseCategoryだけ。秘匿中の演出は階級を受け取らず、共通の未公開報告パネルにする。正本の階級/確率/交渉/公開条件/イベントID・進行は変更なし。実年度ドラフトと外国人段階公開に合成複合選手を用いた回帰。全API秘匿保証ではない：イベントID、候補選定順、契約条件、公開記録、共有・他投影からの推測は別監査。正式採用/本番変更なし。

# H013 暗号化停止時バックアップ試作

PR162の認証付き5DBバックアップを私有一時領域で作り、各DBとmanifestをAES-256-GCMで暗号化する。外部32byte鍵、別経路で信頼したbackupId必須、HKDFで暗号化鍵/HMAC鍵を分離、各ファイル独立ランダム96bit nonce、AADに世代IDとファイル名を束縛。1MiBずつ処理、認証後に既存HMAC/ハッシュ/SQLite検査を通過してから新規復元先へ出す。誤鍵・別世代・切断・改ざん・入替・不明ファイル・上書き拒否の合成試験、実HTTPの2slotとwallet比較。既存v1/v2と別の明示試作API、公開ルートなし。停止・排他は外部前提。一時平文が存在するため信頼できる私有暗号化ストレージを使用する運用が必要。通常終了/例外時に一時領域を削除するが、強制終了/電源断での残存・物理消去・鍵管理・ローテーション・世代台帳・本番監査は未完。本番への接続なし。

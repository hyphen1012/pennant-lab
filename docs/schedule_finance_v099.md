# v0.9.9 — 日程ターゲットと月次資金決済

ユーザー指定：週末まで（日曜消化）、週次報告まで（定期休養日である月曜の球界ニュース）、月次報告まで（月末、最終月はシーズン終了日）、シーズン終了まで。シーズン終了＋スキップに限り、月次・重大負傷報告の確認停止を省略し、報告は履歴に残す。資金不足・保存障害・ブラウザ非表示は停止する。その他の進行は既存の停止条件を維持する。

月次決済は簡易経営モデルを移行：年間基本収入8.5億円を暦日按分、勝利加算6億円×勝数/143、最終月に順位ボーナス1位2.5億円・2位1.2億円。選手年俸と監督報酬は暦日按分で月末精算。全12球団へ同一ルール。最終日で当年の決済が完結し、翌年移行時に再精算しない。旧v2セーブの当年未精算分は次回月末または年末手続きでまとめて決済する。既に翌年へ移行済みの年は再計算しない。簡易モデルであり、施設・広告・経済AIは今後調整。

支払後の現金が負の場合のみ資金不足。資金不足を保存し、進行を停止。実配信未接続のため広告融資ボタンは無効・明記。ゲームオーバー選択を保存し、セーブを勝手に消さない。実広告SDK接続、銀行融資の月利10%・年2回、親会社援助等は設計原則33章に従い後続実装。虚偽の報酬や無料救済は作らない。

## v0.9.10（ユーザー訂正）
週末までの進行は不要との指定により廃止。日程メニューを1日・週次報告・月次報告・シーズン終了の4種類に整理する。旧版で途中停止している週末目標のみ取り消し、日付・成績・その他の進行目標は維持する。

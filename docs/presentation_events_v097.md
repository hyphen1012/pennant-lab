# v0.9.7 — イベントタイトル演出

参考資料 IMG_2223.pdf 12ページのキャンプ地決め、IMG_2275.pdf 21ページの春季キャンプ等、通常の画面と区別されたタイトル演出を参考にした独自設計。

年間表彰式→自球団受賞者（追加タイトルなし）→年間収支の確認→ウインターリーグ→自主トレ→春季キャンプ→新シーズン開幕。6場面で年度、英語ラベル、日本語タイトル、短い説明、落ち着いたフェードを共通表示。冬・春・開幕で差し色を変える。自主トレと春季キャンプは翌年表記。任意の確認ボタンで既存画面へ移る。

タイトルは表示専用。経験値、年次精算、成長・衰退、新年度開始は既存の業務ボタンが実行する。確認済みのタイトルを重複表示しないよう任意のセーブフィールドに記録（v2維持）。月次報告・負傷通知は従来どおり優先、再読み込みしても未確認タイトルを表示できる。日付演出や試合観戦は変更しない。ドラフト等の未実装機能は追加したとみなさない。

# H009 場面別音響の追加試聴・回帰

21の独自合成BGMループ・15のSE試聴パターン。通常特殊3階級を個別化し、IMMORTAL・輪廻転生・複合を含む6階級はそれぞれ別の楽曲パターン。秘匿中は既存の共通テーマ（ドラフト、海外、謎テーマ）を維持し、公開ステージのみ個別化。前世のbaseCategoryは公開済みの再入団・外国人候補情報に限って参照する。

確定済み試合の表示中フレームから本塁打・連続奪三振、最終画面から自球団勝利・敗戦・引分のSEを選ぶ。未来フレーム、未表示結果、別球団、日程スキップには鳴らさない。同じ表示フレームの再描画で重複発音しない。resume/suspendを直列化し、非表示・消音中の遅延復帰と復帰競合を回帰試験。起動動画・本番フラグ・ゲーム正本・確率・報酬は変更なし。

試聴合成音であり正式楽曲・正式意匠・実端末聴感、曲間クロスフェード、重要試合や全イベントへのSE接続は未完。試作値は正式採用しない。

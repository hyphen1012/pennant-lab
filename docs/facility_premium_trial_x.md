# 経営試験X（未採用）
ユーザー承認方針：Lv20への到達は超高難易度だが、施設を最高級にした恩恵を実感できる経営収益とする。Wでは1937=160（52年到達、53年維持、54年球場縮小）、4391=158、8821=159。全seed正式条件未達、人工補填なし。
W基準でLv16〜20の球場に来場者一人あたりの飲食・物販付加価値を各40/85/140/220/560円（試験値）追加。対応する飲食・物販施設Lv10以下は0、Lv20まで段階的、施設状態による減衰あり。従来の売上に合算し飲食58%・物販62%の原価、管理費等は従来計算を適用する。入場者数・チケット価格・建設費・維持費・留保条件は変更しない。自他球団同一のstadiumDemandに適用、試合実績と収支予測共通。現金補填なし。最大効果は球場・売店ともLv20で一人あたり各560円、Lv19→20の追加は各340円（状態100%時）。スポンサー・VIP席価格は今回は変更せず要因を分離する。
全12球団の境界と既存費用を比較し、55年×3seedで50年以内到達＋5年維持を判定。過度な収益増・Lv15以下の経営への波及も監査。採用前に本体へ移植しない。

# v0.9.1 — 日程進行演出

参考資料 IMG_2118.pdf 17ページ、IMG_2223.pdf 8ページ、IMG_2337.pdf 10ページの日付切替を参考にした独自UI。既存の配色と英語の演出ラベルを維持する。

- 日付を処理する前に前後の日付を薄く、当日を中央に大きく表示。開幕戦、リーグ戦、交流戦、休養日等を区別。
- 通常480ms、倍速320ms。連続進行は既存の表示時間からこの分を差し引く（試合日2秒/1秒、新聞5秒）。1日観戦のPLAY BALL・得点・GAME SETは変更しない。
- 一括スキップでは日付演出を省略。カットイン中は一時停止・本部復帰が可能。日付処理前に戻る場合は当日を消費しない。画面の動きを減らす端末設定にも対応。
- 試合計算・セーブ形式・重大負傷や月次報告の停止条件・既存選手アイコンには変更なし。
- 今後はイベントタイトル、ニュースカットイン、結果報告の演出を順次整備する。

## v0.9.2（ユーザー確認後の調整）
日付表示を2倍（通常960ms／倍速640ms）に延長。スクロールのアニメーション速度・試合結果・新聞の閲覧時間はv0.9.1のまま。したがって連続進行の1日あたりの表示時間は通常480ms、倍速320ms増加する。スキップ進行は変更なし。

## v0.9.3（ユーザー確認後の再調整）
通常モードの日付表示を1.5秒へ延長する。倍速640msと他の演出・閲覧時間はv0.9.2のまま。通常の連続進行は前版より1日540ms長くなる。

## v0.9.4（ユーザー確認後の調整）
日付カットインから一時停止ボタンを削除し、この画面のタップによる停止も無効にする。通常1500ms、倍速640msのまま。試合・新聞・結果画面の一時停止と本部復帰、バックグラウンド時の安全停止は従来どおり。

## v0.9.5（ユーザー確認後の調整）
縦スクロールとフェードを通常280ms→950ms、倍速180ms→400msへ延長し、自然な減速カーブに調整。全体の表示時間は1500ms／640msを維持し、静止表示を550ms／240ms確保する。日付の位置・配色・操作制限・スキップ・試合処理は変更しない。端末の動きを減らす設定も維持する。

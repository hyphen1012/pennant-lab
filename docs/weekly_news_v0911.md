# v0.9.11 — 週刊 球界ニュース

月曜日に直前7暦日の実試合記録を集計して新聞を発行する。休養日・交流戦・月跨ぎを含む。自球団の週間勝敗、得失点、対戦相手とスコア、個別の試合成績記録がある自球団選手から注目打者・注目投手を選ぶ。両リーグの当時の順位と全12球団の週間勝敗を記録し、東は青・西は黄を維持。試合のない期間はその旨を明示。記録のない選手成績を捏造しない。

新聞は発行時のスナップショットを保持。本部の新聞履歴または記録→ニュースから年別に閲覧する。旧版の新聞は旧形式のまま表示し、過去の順位を現在の順位から再生成しない。通常の休養日新聞、日付演出、進行停止条件、月次決済、セーブv2は維持。

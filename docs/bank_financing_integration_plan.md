# 銀行融資・親会社援助 — 接続前設計（未承認案を含む）
参照：game_design_principles.md §33。既存の checkFinanceCrisis と権威サーバーの報酬台帳を利用する。現時点では融資の有効化、資金追加、新しい広告ルートの開放はしない。

## 確定事項
- 銀行：月利10%、1シーズン2回まで。実際の支払不能時にのみ救済。ただし優勝年度オフ＋翌シーズンは補強・投資目的の事前申請可。
- 親会社：リーグ優勝・日本一・世界一を獲得した年度のオフ＋翌シーズンで合計1回、利息5%。同年複数タイトルの重複付与なし。次の優勝年度で更新、未使用枠は繰越不可。
- 広告証明なしの銀行融資・無料復活は禁止。融資回数・元本・利息・次回支払額の表示が必要。赤字決算のみでは終了しない。

## 未確定事項（以下は試験候補であり正式仕様ではない）
| 項目 | 試験候補 |
|---|---|
| 融資額 | 実際の不足額を基礎に上限を設け、申請額と必要額を照合 |
| 返済 | 毎月利息＋元本分割、任意繰上返済は未経過分の利息を発生させない方式 |
| 期間 | 12か月、24か月を独立比較 |
| 利息順序 | 支払済み月の再計算禁止、利息を先に支払い元本へ充当 |
| 親会社5% | 月利案と年利案を別々に評価。確定までは実行不可 |
| 年度境界 | シーズンとオフの対応を設計書で確定してからカウンタを実装 |

## 接続・試験条件
1. サーバーのみが世界ID・資金不足ID・負債ID・年度・回数・優勝実績・申請額・返済条件を確定。広告予約と確定を同一操作IDに紐付ける。未確定報酬中の進行制限を維持。
2. 本人・世界・試行番号・SSV証明を照合。融資実行、債務作成、現金追加、回数更新、状態保存は同一トランザクション。再送は新規融資にしない。
3. 月次精算の支払期日を一意化。追加利息、元本返済、資金不足再判定を同一会計期間に一度だけ実行。年度更新で債務を消さない。
4. 権利消滅・広告キャンセル・在庫不足・通信切断・重複コールバック・世界切替・返済不足・3回目の不足・優勝枠重複・オフ境界を試験する。
5. 既存の通常収入やAIに借入を自動注入しない。50+5自然経営の補填禁止を維持。
6. 現行の finance-end と未接続表示は維持。未確定条件・実SSVを解消するまで本番融資ルートは開かない。

## 返済比較モデル（試験専用、採用未決定）
- server/finance-repayment-trial.cjs と scripts/finance-repayment-trial-check.cjs を追加。元本均等分割・期首元本に対する月次利息・端数の四捨五入・繰上返済を整数の試験単位で比較する。本番通貨単位、丸め、融資額、期限、親会社利息周期は未確定。
- 銀行月10%、親会社月5%と年5%を12分割する候補を分ける。例：元本1億円を1万円単位で試算すると銀行12か月は利息6499万円、24か月は12495万円、24か月契約の6か月目完済は5375万円。月次の支払不能も検出する。返済専用の比較で、実ゲーム収支の試験ではない。
- 借入・報酬・広告・台帳・ゲーム進行を変更しない。資格・回数・年度境界・SSV・一意な決済・既存資金不足との接続は引き続き残課題。試験CIを新設。正式採用しない。

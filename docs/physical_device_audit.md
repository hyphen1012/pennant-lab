# PENNANT LAB 実機確認チェックリスト（v0.9.158以降）
2026-11-25。開発用Webの通常セーブとテストシナリオ、ネイティブのテスト広告版、正式配信版の検証を区別する。実機未確認の項目は未判定。既存の設計書が優先であり、ここに新しいゲーム仕様は追加しない。

## 記録の方法
- バージョン、端末・OS、ブラウザ/アプリ、セーブ番号、ゲーム内年度・日付、球団、進行モード、直前の操作、期待と実際を記録。
- 演出はスクリーン録画、操作・表示異常はスクリーンショット。セーブの不具合は可能ならバックアップしてから再現する。テスト用セーブを使い、個人情報や認証情報を送らない。
- P0: データ消失、進行不能、二重課金・報酬、セーブ破損、オンライン制御重大不具合。発見したらそのテストセーブの進行を止める。
- P1: 進行重複/脱落、誤計上、重要演出や秘密能力の漏洩、タップ不能、頻繁なカクつき。P2: 演出品質・文字/余白/配色・改善要望。
- 画面ごとの正常/異常/未確認を区別。CIの成功は目視・実機合格ではない。

## 最優先（通常の開発Webで確認）
| 操作 | 合格条件 |
|---|---|
| 新規作成→1日進める→再読込→同じスロットを開く | 日付・球団・選手・資金・成績が保持 |
| 別スロットで新規球団→元スロットに戻る | 混線・上書きなし。ロード中の連打でも別スロットに移らない |
| 通常/倍速/週次/月次/シーズン終了まで | 指定した日付に到達。通常報告は任意閲覧、重要な通知の扱いは設計書準拠。確認後の再開で同じ試合を重ねない |
| 自動進行中に一時停止→本部→再開 | 日付・残り目標を保持、ボタンが押せる |
| ドラフト1〜3巡目の獲得/調査/追加調査/指名 | 不意にページ先頭に戻らない、演出が見える、選択可能、契約と選手枠の整合 |
| FA解禁前夜→廊下→各部屋→交渉→待機→返答 | マップ・人体/机の重なり・長文・スクロール・移動演出、返答中の通常業務 |
| 春季・秋季キャンプ、冬季派遣、契約更改、表彰、収支 | 日付通りの発生、同時進行可能、結果確認と次業務 |
| 特殊選手演出確認モード | 全10肩書、特にIMMORTAL/輪廻転生の独立した測定不能演出、未入団の秘匿、文字の見切れ、光の強さ |
| 選手詳細/編成/二軍/スカウト | 同一選手の顔、上半身、能力ランク・肩書色が一貫、長押し、情報量 |
| 球場/施設、月例・年間収支、スポンサー、ファンクラブ | 表示と費用・維持費・収益の納得感、Lv5ごとの外観変化、カードプレビュー |
| 記念アルバム・PNG保存 | 過去の実績値・外見、二重記録なし、文字/画像の見切れ、案内OFF、投稿報酬なし |
| 30〜60分の連続操作 | 発熱、引っかかり、スクロール、試合後の表示遅延、メモリ圧迫の兆候 |

## 正式アプリに近いネイティブ試験（テスト広告版）
Android debug APK、iOS Simulator appは署名済みのApp Store配布物ではない。iOS実機には適切な署名・配布経路が別途必要。
| 操作 | 合格条件 |
|---|---|
| 起動、機内モード、Wi-Fi切替、アプリ復帰 | オフラインで進行しない。復帰で勝手に試合を再開しない。再接続後に操作可能 |
| 日付進行中の切断、バックグラウンド、画面ロック | 安全な境界で停止、二重試合・消失なし |
| 保存直後・保存中の強制終了と再起動 | 最後に永続化された状態を読み出せる。破損や古いスロットの上書きなし |
| 広告完了/途中中断/在庫なし/通信断/同意拒否 | 完了時だけ有効な対象に一度付与、他の場合は誤付与なし、通常プレイは広告必須でない |
| 特別治療・FA/引退/監督慰留等 | 正しい対象と条件、同一処理の連打防止。宣伝用画像は本編配色を変更しない |
| PNG・JSONのOS共有、キャンセル | 正しいファイル、キャンセルしても進行・報酬・保存に悪影響なし |
| セーフエリア・文字サイズ・動き低減・戻る操作 | ノッチ/ホームバー/キーボードに隠れず、操作可、演出の軽減対応 |

## 未接続の本番機能
VIP、永久パック、記念報酬、券、ポイント、課金復元/返金/失効、認証、広告の実運用は本番接続後に別監査する。現時点の模擬・参照実装を本番合格扱いしない。500/1000年の手動実機試験は不要。100年耐久と長期セーブは自動試験を主とする。

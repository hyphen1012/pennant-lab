# PENNANT LAB

架空12球団の野球GMシミュレーションゲーム。スマートフォン・PC向け静的Webアプリ。

## 公開版

- 現行 GitHub Pages: v0.2.1（公開URL: https://hyphen1012.github.io/pennant-lab/ ）
- **v0.3.0 はローカル完成版・ブラウザ操作テスト済み。GitHub Pagesへは未反映。** この版では選手の簡易顔アイコン、独自入れ替え画面、7/30試合結果サマリー、シーズン成績画面、タイトル表彰、育成方針・経験値を実装。

## v0.3.0 の更新方法

1. 旧版のゲーム内「経営」からセーブデータを JSON 形式でバックアップ。
2. 配布済みの v0.3.0 HTML を `index.html` という名前でこのリポジトリ直下にコミット（既存の同名ファイルを置き換える）。
3. GitHub Pages が更新されたら https://hyphen1012.github.io/pennant-lab/ から起動する。

同じ URL・ブラウザのまま更新すれば既存ローカルセーブを使い続けられる。端末間・ドメイン間のセーブ共有は自動ではない。

## 開発方針

[ゲームデザイン基本方針](docs/game_design_principles.md) に、育成・SS能力・正当な戦力差・ドラフト指名拒否・複数回補強交渉などの方向性を記録している。

ドラフトや本格交渉AI、価格弾力性と球団経営の詳細システムは今後の開発対象。

# PENNANT LAB

架空12球団を舞台にした、スマートフォン・PC向けの野球GMシミュレーションゲーム。HTML/JavaScriptの静的Webアプリとして公開しています。

## プレイする

- [PENNANT LAB 公開版](https://hyphen1012.github.io/pennant-lab/)
- GitHub `main` の実装バージョン：**v0.9.1（CALENDAR）**。GitHub Pagesの公開反映には時間差が生じる場合があります。

監督AIは代打・代走・守備固め・イニング単位の継投まで実装済み。投球途中の交代や球種・配球の詳細分析、監督の解任交渉、CPU球団の本格的な監督人事、月次実精算と施設・二軍などは引き続き開発途中です。数値や文章だけに依存しないゲーム体験を優先し、日程と試合の演出をv0.8.0から追加しています。今後は重要ニュース、監督・GMとの会話、イベントでの演出も段階的に強化します。現行機能や未実装事項の詳細は[ゲームデザイン基本方針](docs/game_design_principles.md)、選手アイコンの色・平均値・肩書仕様は[ポートレート仕様書](docs/player_portrait_color_spec.md)を参照してください。

## セーブデータ

- 3スロットのセーブ本体は端末内の **IndexedDB** に保存します（異なる端末間では同期されません）。
- 「経営」→「収支・予算」からJSONバックアップの書き出し・読み込みができます。
- 現行セーブ形式は `v=2` のままで、v0.7.0の監督情報は旧v2セーブに補完します。
- ブラウザのサイトデータを消去するとセーブが失われる場合があります。更新前はバックアップを推奨します。

## 開発と検証

- ゲーム本体：`index.html`
- 仕様と意思決定：`docs/game_design_principles.md`
- 構文とロジック検証：`node scripts/check.cjs`
- 模擬ブラウザでの操作・保存・日次進行テスト：`node scripts/smoke.cjs`
- GitHub Actionsで上記検証を実行します。

最新の模擬ブラウザ試験は新規起動・監督雇用・方針設定・保存・PLAY BALL→イニング観戦→GAME SET→結果画面の遷移に加え、**全143試合・858試合カード・12球団それぞれ143試合**を確認済み。Android実機UIと複数年の監督契約・年俸・人事履歴の回帰テストは別途確認対象です。

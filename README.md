# PENNANT LAB

架空12球団を舞台にした、スマートフォン・PC向けの野球GMシミュレーションゲーム。HTML/JavaScriptの静的Webアプリとして公開しています。

## プレイする

- [PENNANT LAB 公開版](https://hyphen1012.github.io/pennant-lab/)
- GitHub `main` の実装バージョン：**v0.8.2（GAME FEEL + GM BRIEFING）**。GitHub Pagesの公開反映には時間差が生じる場合があります。

## 主な実装済み機能

- 東・西の架空12球団／両リーグ143試合／交流戦／DH制
- 年間カレンダーと通常・倍速・スキップの日次進行、休養日新聞、月次報告
- スマホ向けの一時停止・本部へ戻る・続きから再開
- 打順・守備適性・先発ローテーション、疲労・回復・怪我・復帰
- 年度別の成績・表彰と100年超の長期履歴を目指した保存基盤
- v0.7.0：監督候補の比較・雇用、GM方針、継投・盗塁・バント・守備・若手育成への戦術反映、監督との信頼・不満
- v0.7.1：編成選手のカード配色・総合ランク色、GM業務一覧への監督室統合、1日進行のイニング観戦（試合結果へのスキップ・一時停止に対応）
- v0.8.0：PLAY BALL対戦カード、イニング得点演出、GAME SETの勝敗別演出、実成績による注目選手付きリザルト、過去試合も統一した結果画面
- v0.8.1：監督の顔・野手起用/投手起用/采配的中/育成力のS〜F評価・コンパクトな信頼と不満・ゲーム内GM三択指示・辞任意思と契約更新拒否
- v0.8.2：重大負傷と月次報告をスタッフの顔・送信元・見出し付きGMインボックスとして表示。実際の試合・月次集計データに基づき、従来の進行停止を維持
- v0.7.2：観戦スコアボードの1〜9回・合計点をスマホ横スクロールなしで表示。延長戦は下段に表示

監督の代打交代・監督解任、CPU球団の本格的な監督人事、月次実精算と施設・二軍などは開発途中です。数値や文章だけに依存しないゲーム体験を優先し、日程と試合の演出をv0.8.0から追加しています。今後は重要ニュース、監督・GMとの会話、イベントでの演出も段階的に強化します。現行機能や未実装事項の詳細は[ゲームデザイン基本方針](docs/game_design_principles.md)を参照してください。

## セーブデータ

- 3スロットのセーブ本体は端末内の **IndexedDB** に保存します（異なる端末間では同期されません）。
- 「経営」→「収支・予算」からJSONバックアップの書き出し・読み込みができます。
- 現行セーブ形式は `v=2` のままで、v0.7.0の監督情報は旧v2セーブに補完します。
- ブラウザのサイトデータを消去するとセーブが失われる場合があります。更新前はバックアップを推奨します。

## 開発と検証

- ゲーム本体：`index.html`
- 仕様と意思決定：`docs/game_design_principles.md`

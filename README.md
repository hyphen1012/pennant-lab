# PENNANT LAB

架空12球団を舞台にした、スマートフォン・PC向けの野球GMシミュレーションゲーム。HTML/JavaScriptの静的Webアプリとして公開しています。

## プレイする

- [PENNANT LAB 公開版](https://hyphen1012.github.io/pennant-lab/)
- GitHub `main` の実装バージョン：**v0.7.0 第1段階（MANAGER）**。GitHub Pagesの公開反映には時間差が生じる場合があります。

## 主な実装済み機能

- 東・西の架空12球団／両リーグ143試合／交流戦／DH制
- 年間カレンダーと通常・倍速・スキップの日次進行、休養日新聞、月次報告
- スマホ向けの一時停止・本部へ戻る・続きから再開
- 打順・守備適性・先発ローテーション、疲労・回復・怪我・復帰
- 年度別の成績・表彰と100年超の長期履歴を目指した保存基盤
- v0.7.0第1段階：監督候補の比較・雇用、GM方針、継投・盗塁・バント・守備・若手育成への戦術反映、監督との信頼・不満

監督の代打交代・監督解任、CPU球団の本格的な監督人事、月次実精算と施設・二軍などは開発途中です。現行機能や未実装事項の詳細は[ゲームデザイン基本方針](docs/game_design_principles.md)を参照してください。

## セーブデータ

- 3スロットのセーブ本体は端末内の **IndexedDB** に保存します（異なる端末間では同期されません）。
- 「経営」→「収支・予算」からJSONバックアップの書き出し・読み込みができます。
- 現行セーブ形式は `v=2` のままで、v0.7.0の監督情報は旧v2セーブに補完します。
- ブラウザのサイトデータを消去するとセーブが失われる場合があります。更新前はバックアップを推奨します。

## 開発と検証

- ゲーム本体：`index.html`
- 仕様と意思決定：`docs/game_design_principles.md`

- 模擬ブラウザでの操作・保存・日次進行テスト：`node scripts/smoke.cjs`
- GitHub Actionsで上記検証を実行します。

最新の試験は新規起動・監督雇用・方針設定・1日の進行と保存まで。Android実機UIや143試合・複数年の**v0.7.0回帰テストは別途確認対象**です。
